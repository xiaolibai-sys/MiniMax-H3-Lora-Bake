# Bake MiniMax H3 Pruned LoRA Into Base Weights

Bakes a complete pruned MiniMax H3 LoRA into the base model so inference has
no per-step LoRA overhead. The script preserves ComfyUI's `comfy_quant`
quantization metadata and writes the result back as a normal ComfyUI
safetensors checkpoint.

## Requirements

- Run with ComfyUI's bundled Python:

```powershell
D:\ComfyUI-installs\ComfyUI\ComfyUI\.venv\Scripts\python.exe bake_into_weights.py
```

- A pruned MiniMax H3 base model, preferably the int8 convrot variant.
- A complete pruned LoRA generated by `MiniMax H3 Pruned LoRA Adapter`.

## Config

Copy `config.example.json` to `config.json` and edit it:

```json
{
  "base_model": "path/to/pruned_int8_convrot.safetensors",
  "loras": [
    {
      "path": "path/to/complete_pruned_lora.safetensors",
      "strength": 1.0
    }
  ],
  "output": "path/to/baked_model.safetensors",
  "device": "cuda",
  "compute_dtype": "bfloat16",
  "fold_dtype": "float32",
  "convrot_groupsize": 256,
  "comfy_root": "D:\\ComfyUI-installs\\ComfyUI\\ComfyUI"
}
```

`fold_dtype` controls the arithmetic used for LoRA folding. Keep it as
`float32`: quantized weights are dequantized to FP32, folded in FP32, and
then requantized back to the original ComfyUI layout.

`strength` scales the AdaLN delta relative to the original pruned base table.
For a LoRA already baked at strength 1.0, keep this at 1.0.

## What it does

1. Dequantizes ComfyUI quantized weights.
2. Folds backbone LoRA/DoRA into the dequantized weights in FP32.
3. Combines and replaces `adaln_t_table` and all pruned AdaLN projections in FP32.
   LoRA's values.
4. Re-quantizes with the original layout (`int8_tensorwise`, `convrot`, etc.).
5. Writes `weight`, `weight_scale`, and `comfy_quant` back in ComfyUI format.

The output model is fixed: the LoRA cannot be toggled or re-scaled later.
